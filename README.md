# CtrlAlt

Приложение в строке меню macOS: Windows-сочетания на внешней PC-клавиатуре. Встроенная клавиатура MacBook работает как обычно.

CtrlAlt — надстройка над [Karabiner-Elements](https://karabiner-elements.pqrs.org/). Сам ввод обрабатывает Karabiner (драйвер и сервис pqrs.org), а CtrlAlt даёт выбрать клавиатуру и включить нужные группы сочетаний галочками — без ручного JSON.

## Что умеет

| На внешней клавиатуре | Результат |
|---|---|
| Alt+Tab, Alt+Shift+Tab | Стандартный переключатель приложений macOS, открыт пока держишь Alt |
| Левые Alt+Shift, Win+Space | Смена раскладки (системное Ctrl+Space) |
| Win | Spotlight |
| Win+Ctrl+←/→ | Соседний рабочий стол |
| Ctrl+C/V/X/A/Z/S/F/T/W… | Command+… (кроме терминалов) |
| Ctrl+Y | Повтор (Command+Shift+Z) |
| Ctrl+Q/H/M | Остаются обычным Ctrl, чтобы случайно не закрыть или не скрыть приложение |
| Ctrl+←/→, Ctrl+Backspace/Delete | По словам |
| Home/End | Начало и конец строки |
| Ctrl+колесо мыши | Масштаб (Command+= / Command+-) |

В терминалах (Terminal, iTerm2, Ghostty, kitty, Alacritty, WezTerm, Warp) Ctrl остаётся Ctrl, копирование и вставка — Ctrl+Shift+C/V. В VS Code Ctrl+C тоже остаётся Ctrl (прерывание во встроенном терминале).

## Установка

1. Установите [Karabiner-Elements](https://karabiner-elements.pqrs.org/) и пройдите его первоначальную настройку (драйвер, Input Monitoring).
2. Откройте `CtrlAlt-<версия>.dmg` и перетащите CtrlAlt в «Программы».
3. Запустите CtrlAlt: в строке меню появится значок клавиатуры.
4. Выберите внешнюю клавиатуру. Правила записываются в Karabiner сразу.
5. Для масштаба колесом нажмите «Разрешить» и включите CtrlAlt в «Универсальном доступе».

## Как это работает

- CtrlAlt записывает правила в выбранный профиль `~/.config/karabiner/karabiner.json`. Свои правила он узнаёт по описанию, которое начинается с `CtrlAlt`, а чужие правила, F-клавиши и остальные настройки не трогает.
- Правила, которые записывались вручную до CtrlAlt (описание начинается с `KD83A 0416:7472`), CtrlAlt заменяет своими при первом изменении настроек.
- Конфиг меняется только при изменении настроек в меню, а запуск приложения ничего не записывает. Перед каждой записью делается бэкап в `~/.config/karabiner/ctrlalt_backups/` (хранятся последние 20).
- Перед записью правила проверяются линтером Karabiner (`karabiner_cli --lint-complex-modifications`).
- Колесо мыши Karabiner не обрабатывает, поэтому масштаб сделан в самом CtrlAlt: event tap на уровне HID забирает только Ctrl+колесо, остальная прокрутка идёт в Mos как обычно.

## Разработка

Нужны Command Line Tools (Xcode не обязателен).

```bash
swift run CtrlAltChecks        # проверки логики
./scripts/build-app.sh         # build/CtrlAlt.app
./scripts/make-dmg.sh          # build/CtrlAlt-<версия>.dmg
swift scripts/make-icon.swift  # перерисовать Resources/AppIcon.icns
```

Отладочные режимы:

```bash
.build/debug/CtrlAlt --print-rules 0416:7472   # правила в формате complex modifications
.build/debug/CtrlAlt --snapshot menu.png       # нарисовать меню в PNG
```

`Sources/CtrlAltChecks/Fixtures/kd83a-verified.json` — правила, проверенные вручную на клавиатуре KD83A. Проверки сравнивают с ними вывод генератора, поэтому менять этот файл стоит только после новой проверки на клавиатуре.

Версия хранится в `VERSION`.

## Ограничения

- Подпись локальная (ad-hoc). После каждой пересборки macOS может забыть разрешение «Универсальный доступ» — тогда выключите и снова включите CtrlAlt в настройках.
- Ctrl+колесо срабатывает и с Ctrl встроенной клавиатуры: macOS не сообщает, с какой клавиатуры нажат модификатор.
- Если зажать Win, кликнуть мышью и быстро отпустить Win, может открыться Spotlight: Karabiner не видит клики мыши, которую он не обрабатывает.
- Одна выбранная клавиатура; правила привязаны к VID/PID модели.
- Если сочетания не действуют, проверьте в Karabiner → Devices, что для клавиатуры включено «Modify events».

## Удаление

Выключите переключатель в меню CtrlAlt (правила удалятся из Karabiner), затем удалите приложение из «Программ».
